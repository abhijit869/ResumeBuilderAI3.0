Enterprise Authentication, Login Gateway & Admin Access
Objective

Build a secure, enterprise-grade authentication system for an AI Resume Builder SaaS application.

The authentication system must be modern, responsive, highly secure, and production-ready.

Do not use hidden backdoors or client-side secrets.

Default Administrator

On the first application setup, automatically create a default administrator account if one does not already exist.

Example configuration:

Email:
admin123@gmail.com

Role:
Super Admin

Status:
Active

The password must not be hardcoded in the frontend. Instead, it should be stored securely as a hashed value on the server and configurable through environment variables or a secure setup process.

If the user logs in with the administrator account and valid credentials:
